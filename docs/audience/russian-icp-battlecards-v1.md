# Русские ICP battlecards V1

Собрано: 2026-05-31T11:55:02.415Z

## Зачем нужен этот файл

Этот слой переводит audience/ICP data в русские карточки сегментов. Он нужен, чтобы отчет говорил не абстрактно "есть аудитория", а последовательно показывал: кто этот человек, какую работу он уже пытается выполнить, почему он важен для Alina, где его искать, как его отсеивать и по какому тесту сегмент можно усилить или отбросить.

Важно: карточки не являются доказательством выбранного ICP. Это evidence-backed план полевой проверки. Сегмент можно поднять в статус выбранного только после интервью, прототипной сессии и WTP/objection capture.
