## Evidence Handling Rules

- Treat outreach copy as a starting script, not a claim of channel-market fit.
- Recruit only through opt-in, transparent, rule-compliant channels.
- Upgrade an ICP only after recent behavior, problem episode, prototype comprehension, differentiation, and paid-depth evidence are captured.
- Downgrade a segment if participants cannot name recent behavior, interpret the loop as generic, or raise fatal trust/safety objections.
